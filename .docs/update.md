# 更新记录

## 2026-11-19
- 主窗口启动居中；所有弹窗取消点击遮罩关闭。
- 模型下拉改为纯原生选择，移除误打开配置弹窗，补齐工具栏样式。
- 发送消息后立即清空输入框，不再等待流式生成结束。
- 新增右侧生成文件面板（文件列表 + 内容预览 + 复制/打开），替换消息内折叠块与居中预览弹窗；顶部模型标签改为面板开关。
- 恢复「高级设置」入口（工作目录、生成参数、工具策略、外观、系统提示词）；「模型设置」仍打开服务商弹窗。
- 生成过程显示累计用时与各工具步骤耗时；模型未返回思考文本时给出明确提示，不再隐藏思考区域。
- 修复登录令牌与 API Key 每次重启丢失：启用 keyring 的 Windows 原生凭据后端，并统一本地回退文件的读写键名。
- 供应商配置改为单表单布局，新增思考强度、工具调用/图片输入/推理能力开关与输入输出 token 配置，参数已写入模型请求与对话上下文预算。
- 修复网络异常后仍停留在“停止生成”状态：支持立即中断等待中的模型请求，并将底层网络错误转为可读提示。
- 增加面板拖拽分隔条：侧边栏、聊天区/生成文件面板、文件列表/预览区均可手动调整宽度。
- 输入框支持上传常见文本、代码与配置附件并随消息发送；服务商显示名称可编辑，模型下拉旁新增“编辑当前模型”，新增服务商区域文案更清晰。
- 新增 `publish.bat`：输入版本号后同步前端/后端/打包版本，构建 Release 安装包并复制到 `publish` 目录。
- 输入框宽度恢复为舒适固定宽度，不再随窗口拉长；支持将文本、代码与配置文件直接拖入输入框添加为附件。
- 技能改为按轮次选择：菜单可勾选/取消，选中后以 `@技能名` 显示在输入框，发送时仅注入选中技能。
- 输入框与消息正文左对齐；生成过程中输入新指令后按回车，会自动中止当前生成并立即发送新指令。
- 修复仅返回思考过程或空正文时出现空白回答气泡：中止不再保存部分思考，空响应会显示明确说明。
- 模型只思考不返回正文时自动关闭思考重试一次；中断后重发相同指令不再重复添加用户消息。
- 思考过程与工具调用输出时自动滚动到底部；检测到重复工具调用会强制模型直接给最终答案，避免无限工具循环。
- 修复命令工具执行卡死：自动识别 PowerShell 命令并去除多余包装，输出管道并发读取，超时或点击停止生成会终止整个进程树。
- 生成中的思考区取消内部高度限制，始终位于消息末尾并随外层滚动条自动跟随最新内容。
- 命令工具执行时强制 UTF-8 输出编码，修复 Windows 中文路径/技能名称在工具结果里显示乱码。
- 工具执行失败也会返回结果事件；生成结束/失败/取消会关闭残留“执行中”状态，并增加常见中文乱码自动修复。
- 生成过程改为豆包式交错显示：正文、思考和工具状态按发生顺序排列，工具默认收起为“已执行代码/正在执行代码”一行，可展开查看参数与结果。
- 新增自动子智能体：主模型自动拆分最多 4 个只读分析任务，并发 3 执行，结果汇总后由主模型输出最终答案；停止生成会一并中止所有子任务。

## 2026-11-20
- 修复中文名技能包安装后目录乱码、v8 包反复安装失败：解压按 UTF-8/GBK 修复条目名，技能统一以中文名识别。
- 新增技能参考文件按需读取：激活返回文件清单，模型用 read_skill_reference 读取全文，解决分镜等工位读不到 references 规则的问题。
- 技能扫描、注入、激活、参考文件读取全程写入日志，便于诊断。
- 输入区工具栏新增「工作项目」下拉：新建项目（默认建在应用数据目录的 projects）、从本地目录选择、不使用项目，带状态提示。
- 修复 release 版本弹出黑色控制台：主程序改用 Windows GUI 子系统，命令/终止子进程通过 Rust creation_flags 静默运行，无需脚本或额外权限。
- 交付文件随消息持久化：助手消息下方显示文件卡片，单击预览、右键在文件管理器中定位，切换会话或重启不丢失。
- 思考过程改为轻量折叠行（已完成思考 / 正在思考），点击展开内容，去掉原边框大块样式。
