# 更新记录

## 2026-11-19
- 主窗口启动居中；所有弹窗取消点击遮罩关闭。
- 模型下拉改为纯原生选择，移除误打开配置弹窗，补齐工具栏样式。
- 发送消息后立即清空输入框，不再等待流式生成结束。
- 新增右侧生成文件面板（文件列表 + 内容预览 + 复制/打开），替换消息内折叠块与居中预览弹窗；顶部模型标签改为面板开关。
- 恢复「高级设置」入口（工作目录、生成参数、工具策略、外观、系统提示词）；「模型设置」仍打开服务商弹窗。
- 生成过程显示累计用时与各工具步骤耗时；模型未返回思考文本时给出明确提示，不再隐藏思考区域。
- 修复登录令牌与 API Key 每次重启丢失：启用 keyring 的 Windows 原生凭据后端，并统一本地回退文件的读写键名。
- 供应商配置改为单表单布局，新增思考强度、工具调用/图片输入/推理能力开关与输入输出 token 配置，参数已写入模型请求与对话上下文预算。
- 修复网络异常后仍停留在“停止生成”状态：支持立即中断等待中的模型请求，并将底层网络错误转为可读提示。
- 增加面板拖拽分隔条：侧边栏、聊天区/生成文件面板、文件列表/预览区均可手动调整宽度。
- 输入框支持上传常见文本、代码与配置附件并随消息发送；服务商显示名称可编辑，模型下拉旁新增“编辑当前模型”，新增服务商区域文案更清晰。
- 新增 `publish.bat`：输入版本号后同步前端/后端/打包版本，构建 Release 安装包并复制到 `publish` 目录。
- 输入框宽度恢复为舒适固定宽度，不再随窗口拉长；支持将文本、代码与配置文件直接拖入输入框添加为附件。
- 技能改为按轮次选择：菜单可勾选/取消，选中后以 `@技能名` 显示在输入框，发送时仅注入选中技能。
